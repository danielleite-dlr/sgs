> Contrato de validação da fase, para amostrar feedback durante a execução. Fonte: `04.1-RESEARCH.md` § Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Jest 29 + ts-jest (backend unit/integração), Vitest 2 (frontend), Playwright (E2E) |
| **Config file** | `apps/backend/jest.config.ts`, `apps/backend/jest-integration.config.ts`, vitest do `apps/frontend`, `apps/e2e/playwright.config.*` |
| **Quick run command** | `pnpm --filter @sgs/backend test -- contracts` · `pnpm --filter @sgs/frontend test -- bridal` |
| **Full suite command** | lint + typecheck + unit + `test:integration` (backend), lint + typecheck + vitest (frontend), `pnpm --filter @sgs/e2e test:e2e` |
| **Estimated runtime** | ~30 s quick · ~10 min suíte completa |

---

## Sampling Rate

- **After every task commit:** testes do módulo tocado + lint/typecheck do pacote
- **After every plan wave:** backend unit completo + integração `phase4-*`/`phase41-*` + frontend vitest
- **Before `/gsd:verify-work`:** suíte completa verde (gate do usuário)
- **Max feedback latency:** 60 seconds (quick)
